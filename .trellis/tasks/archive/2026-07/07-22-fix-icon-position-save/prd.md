# 修复图标拖拽后位置保存问题

## 目标
修复程序退出后图标位置发生变化的bug

## 需求
- 当图标从覆盖区域或分类框拖拽到另一个分类框时，程序退出后图标的原始位置应被保留
- 例如：图标'微信'在程序运行前位于位置A，拖拽到分类框后程序退出，图标应仍位于位置A

## 验收标准
- [ ] 拖拽图标到分类框后，程序退出，图标恢复到原始桌面位置
- [ ] 覆盖区域内的图标拖拽到分类框后，覆盖位置信息被保留
- [ ] 分类框之间的图标拖拽不影响桌面位置

## 技术笔记
- 涉及模块：drag_handler.rs, drag_drop.rs, overlay_window.rs, icon_hider.rs
- 关键函数：save_overlay_icon_positions(), ingest_icon(), restore_all_hidden_icons()
- 需要添加诊断日志来定位具体问题点
