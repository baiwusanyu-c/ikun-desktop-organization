# 覆盖区域 Grid 布局 - 图标拖拽到透明格子

## 目标
将桌面覆盖窗口的图标管理改为严格的网格（Grid）布局模式。覆盖区域被划分为一个个图标大小的透明格子，拖拽图标就是在格子之间移动，支持多屏幕不同分辨率。

## 已知信息
* 覆盖窗口是全屏透明分层窗口，使用 D2D/DirectWrite 渲染
* overlay_layout_params() 已计算 cell_w/cell_h/cols 等网格参数
* 图标位置用逻辑像素（96 DPI 基准）存储在 OverlayIconItem.x/.y
* 拖拽释放时 restore_dragged_icon_position 将图标放在任意像素位置（非网格吸附）
* 已有 per-monitor DPI 支持
* 自动布局图标使用列优先排列

## 需求
1. 覆盖区域显示为网格（透明格子），每个格子 = cell_w x cell_h
2. 拖拽图标释放时，snap 到最近的格子
3. 若目标格子有图标，交换位置
4. 新图标加入时自动找第一个空闲格子
5. 支持多屏幕不同分辨率/DPI

## 验收标准
- [ ] 拖拽图标释放后吸附到网格格子
- [ ] 格子不重叠（每格最多一个图标）
- [ ] 拖拽到有图标的格子上时两图标交换
- [ ] 新增图标自动放到空闲格子
- [ ] 多屏幕不同 DPI 下网格计算正确
- [ ] cargo build 编译通过

## 明确排除范围
* 不改变分类框的布局逻辑
* 不实现拖拽过程中的视觉格子高亮（后续优化）
