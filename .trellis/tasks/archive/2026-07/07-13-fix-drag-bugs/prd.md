# 修复分类框到覆盖区域拖拽 Bug

## 目标
修复两个拖拽相关的 Bug，提升用户体验。

## 需求

### Bug 1: Public 图标移动到覆盖区域后不显示
- **现象**: 从分类框拖拽图标到覆盖区域时，public 桌面图标不显示，user 桌面图标正常
- **根因**: `icon_hider::export_icon()` 使用 `std::fs::rename` 从仓库导出到用户桌面。当仓库与目标不在同一卷时，rename 失败
- **修复**: 添加跨卷回退逻辑（copy + delete）

### Bug 2: 多显示器环境下拖拽受限
- **现象**: 从屏幕A的分类框拖拽图标到屏幕B的覆盖区域时，图标只显示在屏幕A的边缘
- **根因**: 
  1. 覆盖窗口仅创建在光标所在的单个显示器上
  2. `SetCapture` 限制了鼠标消息的传递
  3. 跨显示器时坐标计算不正确
- **修复**: 
  1. 为每个显示器创建独立的覆盖窗口
  2. 改进拖拽坐标计算逻辑

## 验收标准
- [ ] Public 桌面图标拖拽到覆盖区域后正常显示
- [ ] 多显示器间可自由拖拽图标
- [ ] 现有单元测试通过
- [ ] 编译无警告

## 技术备注
- Bug 1 修复范围小，主要修改 `icon_hider.rs` 的 `export_icon` 函数
- Bug 2 修复涉及多文件，需要重构覆盖窗口创建逻辑
