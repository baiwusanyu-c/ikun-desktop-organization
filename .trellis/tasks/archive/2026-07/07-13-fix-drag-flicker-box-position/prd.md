# 修复副屏拖拽闪烁和分类框位置错误

## 目标
修复两个 UI 相关的 bug：副屏幕拖拽时主屏幕闪烁、新建分类框位置不正确。

## 需求
- 修复副屏幕分类框/覆盖区域拖拽图标时，主屏幕左上角闪烁图标的问题
- 修复新建分类框默认出现位置错误，应出现在主屏幕中央（与'创建分类框'窗口行为一致）

## 验收标准
- [ ] 在副屏幕拖拽图标时，主屏幕不会出现任何闪烁
- [ ] 新建分类框默认出现在主屏幕中央
- [ ] cargo fmt/clippy/test 全部通过
- [ ] 不影响其他现有功能

## 技术笔记
- 项目使用 Rust + GPUI 框架
- Windows 平台使用 Direct2D/DirectWrite 渲染
- 涉及多显示器坐标系统
