## 手动行为核对清单

### 控制面板

- [ ] 启动后控制面板不干扰用户；不显示任务栏入口。
- [ ] 系统托盘双击/菜单可打开控制面板。
- [ ] 控制面板标题为 `Desktop Organizer 控制面板`。
- [ ] 控制面板内容尺寸约 `320 x 380`，可 resize。
- [ ] 打开时在鼠标所在显示器工作区居中并置前。
- [ ] 点击窗口 X 时隐藏控制面板，不退出应用。
- [ ] `🔄 一键分类` 行为保持一致。
- [ ] `🗑 清除 & 恢复` 行为保持一致。
- [ ] `💾 保存配置` 行为保持一致。
- [ ] `➕ 创建分类框` 打开创建分类框。
- [ ] 状态消息、原生图标隐藏提示、当前格子数和底部说明文案保持一致。

### 创建分类框

- [ ] 控制面板按钮可打开创建分类框。
- [ ] 系统托盘 `创建分类框` 可打开创建分类框。
- [ ] 信号文件 `ikun_create_box.signal` 可打开创建分类框。
- [ ] 分类框右键菜单 pending create box 可打开创建分类框。
- [ ] 窗口标题为 `创建分类框`。
- [ ] 内容尺寸约 `360 x 180`，不可 resize，窗口带 OS 标题栏。
- [ ] 打开时使用鼠标所在显示器工作区：`360 x 200` 物理像素估算，水平居中，垂直三分之一处。
- [ ] 每次打开都清空输入框。
- [ ] 重复打开不创建多个同名 dialog window，且清空、置前、重新定位。
- [ ] 空白/全空格输入不可确认，提示 `名称不能为空`。
- [ ] 超过 16 字符不可确认，提示 `⚠ 最多 16 字符（当前 N）`。
- [ ] 有效输入提示 `✓ N/16`。
- [ ] 16 字符上限按 `chars().count()`，中文按字符计数。
- [ ] 点击 `确定` 与 Enter 均确认并创建分类框。
- [ ] 点击 `取消`、ESC、窗口 X 均取消且不创建分类框。
- [ ] 确认后调用现有创建逻辑，创建空分类框、保存配置并显示 `已创建分类框「...」` 状态消息。
