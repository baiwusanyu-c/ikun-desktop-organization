# 多选图标右键菜单功能

## 目标
实现分类框内多选图标的右键上下文菜单，使其行为与原生 Windows 桌面图标多选一致。通过代理转发模式，将右键操作代理到 hidden_icons 中真实的图标上执行。

## 需求
- 多选图标右键弹出 Shell 上下文菜单（与原生桌面多选一致）
- 支持跨分类框多选图标的右键操作
- 兼容 public 和 non-public（hidden_icons）图标混选场景
- 右键菜单操作后正确处理各选中项的状态（删除、剪切、重命名等）

## 验收标准
- [ ] 多选图标后右键弹出 Shell 上下文菜单
- [ ] 菜单内容包含：打开、剪切、复制、删除、重命名等标准项
- [ ] 删除操作正确删除所有选中项的 vault 副本
- [ ] 剪切操作正确监控所有选中项的粘贴状态
- [ ] 重命名操作仅在单选时可用（多选时禁用）
- [ ] 跨分类框多选时正确显示菜单
- [ ] public 和 non-public 图标混选时正确显示菜单
- [ ] 右键空白区域仍显示桌面上下文菜单
- [ ] 右键未选中的图标时，清除多选并显示单选菜单

## 技术笔记
- 使用 Shell COM API 的 GetUIObjectOf 支持多 PIDL 参数
- 需要按父文件夹分组处理：同一文件夹内的多项可一次 GetUIObjectOf
- 跨文件夹的多选需要降级处理（取第一个分组或使用简化菜单）
- 多选状态通过 shared::selection 模块管理
- 右键时需先检查 multi_select 状态，再决定走单选还是多选流程
