# 修复分类框小图标透明留白

## 目标

让包含大面积透明画布的应用图标在分类框中按有效图形区域显示，避免图标内容看起来远小于同一视图模式下的其他图标。

## 需求

- HICON 转换为 D2D 位图时裁掉外围全透明像素。
- 裁剪后的非正方形图标保持原始宽高比，并在现有图标区域内居中。
- 分类框、桌面覆盖区和拖拽残影继续复用同一图标绘制入口。
- 不调整网格单元、标签位置或视图模式的配置尺寸。

## 验收标准

- [x] 有透明留白的图标视觉内容能合理填满图标区域。
- [x] 原本铺满画布的图标大小不变。
- [x] 非正方形图标不被拉伸。
- [x] 相关单元测试和 `cargo test` 通过。

## 技术笔记

- 修改 `src/platform/windows/d2d_render.rs` 中的统一 HICON 绘制链路。
- alpha 有效边界计算保持为纯函数，便于覆盖边界条件。
