# 修复液态玻璃圆角上限与裁切阴影直角

## 目标

将控制面板中液态玻璃圆角半径的最大值从 100 收紧为 30，并修复分类框圆角附近因外投影被原生窗口矩形边界裁切而出现的视觉直角。

## 已知信息

- Windows 默认控制面板使用 GPUI，legacy `eframe-ui` 路径也包含同一组液态玻璃设置。
- 两套设置 UI 的圆角滑块上限均为 100，配置层 `set_param` 同样将值限制到 100。
- 默认圆角为 32，超过新的上限 30，因此默认值也必须同步收紧。
- 液态玻璃 shader 使用圆角矩形 SDF 生成主体 alpha，同时把向下偏移的高斯外投影加入窗口 alpha。
- D3D11 输出纹理、D2D 位图与 `WS_EX_LAYERED` 分类框窗口都严格等于分类框宽高，`padding` 为 0，外投影没有透明留白空间。
- 外投影到达纹理四边时被矩形裁切，圆弧投影与裁切边相交后形成截图中的直角边。

## 方案对比

### 方案 A：禁用 shader 外投影（未采用）

- 优点：直接消除被裁切的像素；保留玻璃主体、圆角抗锯齿、边缘高光与折射；不改变窗口尺寸、布局和命中测试。
- 缺点：分类框不再带外部投影。
- 适用：本次缺陷修复，风险最低。

### 方案 B：为分类框窗口增加透明投影留白（采用）

- 优点：可完整保留柔和外投影。
- 缺点：需要扩大原生窗口并为所有标题栏、图标、滚动、拖拽、缩放、命中测试和持久化坐标引入内容偏移，回归面较大。
- 适用：本次用户明确要求保留完整外投影，因此采用该方案，并把内容坐标转换集中到公共 helper。

### 方案 C：把外投影改为内阴影

- 优点：无需扩大窗口。
- 缺点：视觉语义不同，可能让玻璃边缘显脏或压暗内容。
- 适用：明确需要强化内侧层次时。

## 需求

- [x] legacy egui 液态玻璃圆角滑块最大值为 30。
- [x] 配置入口对圆角参数执行 0~30 的统一约束。
- [x] 默认圆角值不超过新上限。
- [x] shader 在带透明留白的扩展表面内保留完整外投影。
- [x] 保留现有玻璃折射、模糊、圆角抗锯齿和内侧边缘高光。
- [x] 标题拖动、边缘缩放、锁定/更多按钮、标题双击、图标点击/拖拽/框选全部使用内容坐标。

- [ ] 分类框内图标可点击、双击、拖拽和框选，跨框/桌面拖放位置无偏移。
- [x] 液态玻璃关闭时的半透明回退背景行为不变。

## 明确排除范围

- 本任务不改变用户可见内容尺寸、布局与持久化语义；原生窗口只增加用于外阴影的透明留白。
- 本任务不新增可配置阴影参数。
- 本任务不修改 macOS 渲染路径。

## 技术笔记

- 圆角上限定义在配置模块中作为单一事实来源，两套 UI 与配置 setter 复用同一常量。
- 分类框原生窗口、D3D11 输出和 D2D 目标四周增加 DPI 感知的 128 逻辑像素留白，shader 通过 `padding/lensSize` 在扩展表面内绘制主体与完整外阴影。
- 所有鼠标客户区坐标先减去 shadow padding；所有屏幕矩形命中、菜单锚点、拖放定位与持久化先转换为 content rect。
- 回归测试覆盖圆角上限、shader 外阴影与 DPI 感知的内容矩形/客户坐标转换。
- 自动检查结果：`cargo fmt -- --check`、`cargo check`、`cargo clippy` 均通过；`cargo test` 381/381 通过（保留仓库既有 warnings）。
