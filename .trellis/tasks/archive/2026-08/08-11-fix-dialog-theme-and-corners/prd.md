# 修复弹窗圆角与主题联动

## 目标

修复控制面板、创建分类框和编辑分类框的窗口边缘与主题色表现。

## 需求

- 控制面板悬停关闭按钮时，右上角保持与窗口一致的圆角裁剪。
- 创建和编辑分类框四周不显示白色边距或尖角。
- 创建和编辑分类框的输入框焦点态、确认按钮跟随当前主题色。
- 控制面板修改主题色后，已经创建的持久分类弹窗立即同步。
- 缩短输入区域与取消、确认按钮之间的垂直间距。

## 验收标准

- [x] 三个窗口的四角均由同一容器裁剪，关闭按钮悬停不破坏圆角。
- [x] 分类弹窗窗口边界无额外白边或外层阴影带。
- [x] 主题色变化可实时传播到创建和编辑窗口。
- [x] 两个分类弹窗布局一致，错误消息出现时不遮挡按钮。
- [x] `npm --prefix frontend run check` 通过。
- [x] `npm --prefix frontend run build` 通过。

## 技术说明

主题同步使用 Tauri 全局事件；窗口重新显示时再次读取配置作为兜底。样式修改集中在共享窗口样式和两个弹窗页面，不改变关闭即隐藏的生命周期。
