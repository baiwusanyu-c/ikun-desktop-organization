# 优化分类框 UI

## Goal
优化桌面分类框的视觉效果和交互行为

## Requirements
- 分类框根据屏幕分辨率自动调整大小
- 标题和主体颜色统一为黑色（0.3 透明度），标题文字放大
- 标题区域拖拽移动，主体四边+四角拖拽调整大小（标题区域不支持缩放）

## Acceptance Criteria
- [ ] 不同分辨率/DPI下框大小合适
- [ ] 标题和主体颜色一致，纯黑背景
- [ ] 标题文字清晰可读
- [ ] 拖拽标题栏移动整个框
- [ ] 拖拽主体边缘和角落调整大小

## Technical Notes
- 修改 grid_window.rs: DPI 感知、颜色、hit test
- 修改 app.rs: 动态计算框尺寸
