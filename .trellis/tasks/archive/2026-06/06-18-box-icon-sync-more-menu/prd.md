# 分类框图标同步 + "更多"下拉菜单

## Goal
解决分类框图标与桌面实际图标不同步的问题，并为分类框添加"更多"操作菜单入口。

## Requirements

### R1: 启动时图标同步（过滤已删除图标）
- 应用启动恢复布局时，验证每个分类框中的文件是否仍然存在于桌面
- 不存在的文件（已被用户删除）从分类框的文件列表中移除
- 确保分类框显示的图标始终与桌面实际图标一致
- 同步在 `restore_layout` 或布局加载阶段执行

### R2: "更多"按钮（⋮ 三个竖点）
- 在标题栏锁定按钮（🔒/🔓）右侧添加"更多"按钮
- 图标：三个竖着的圆点（⋮），使用 Segoe UI Emoji 或类似字体
- 鼠标 hover 时显示手型光标 + 半透明背景高亮（与锁定按钮风格一致）
- 点击按钮切换下拉菜单的显示/隐藏

### R3: 下拉菜单
- 从"更多"按钮下方弹出
- 菜单结构和交互规则：

```
┌──────────────┐
│ 删除         │  ← 点击触发预留函数 + 日志
├──────────────┤
│ 排序      ▶  │  ← hover 展开二级菜单
│  ├ 名称      │     8 种维度单选
│  ├ 类型      │     +
│  ├ 修改时间  │     递增/递减 单选
│  ├ 作者      │     （两组独立选择）
│  ├ 创建时间  │
│  ├ 大小      │
│  ├ 标记      │
│  └ 标题      │
│  ──────────  │
│  ▲ 递增  ✓   │
│  ▼ 递减      │
├──────────────┤
│ 分组      ▶  │  ← hover 展开二级菜单
│  ├ 名称      │     8 种维度单选
│  ├ 类型      │
│  ├ 修改时间  │
│  ├ 作者      │
│  ├ 创建时间  │
│  ├ 大小      │
│  ├ 标记      │
│  └ 标题      │
├──────────────┤
│ 查看      ▶  │  ← hover 展开二级菜单
│  ├ 超大图标  │     8 种视图单选
│  ├ 大图标    │
│  ├ 中图标    │
│  ├ 小图标    │
│  ├ 列表      │
│  ├ 详细信息  │
│  ├ 平铺      │
│  └ 内容      │
└──────────────┘
```

- 排序：维度 8 选 1（单选），递增/递减 2 选 1（单选），两组独立可同时选择
- 分组：8 选 1（单选）
- 查看：8 选 1（单选）
- 点击菜单项后预留处理函数，函数内打印日志即可（如 `log_info!("排序方式切换为: 名称 递增")` ）
- 点击菜单项或菜单外区域关闭菜单
- 当前选中项显示 ✓ 标记

### R4: 菜单状态管理
- 菜单打开/关闭状态（在 GridWindowData 或交互状态中）
- 当前选中的排序维度 + 升降序
- 当前选中的分组维度
- 当前选中的查看模式
- 选中状态持久化到配置（可选，至少运行时正确）

## Acceptance Criteria
- [ ] 启动后分类框不显示已删除的桌面图标
- [ ] 标题栏锁定按钮右侧显示"更多"按钮（⋮）
- [ ] 点击"更多"按钮弹出下拉菜单
- [ ] 菜单包含删除、排序、分组、查看四个一级项
- [ ] 排序/分组/查看各有二级子菜单（hover 展开）
- [ ] 排序维度 8 选 1、递增/递减 2 选 1、两组独立
- [ ] 分组 8 选 1
- [ ] 查看 8 选 1
- [ ] 当前选中项有 ✓ 标记
- [ ] 点击菜单项触发预留函数（打印日志）
- [ ] 点击菜单外区域关闭菜单
- [ ] `cargo check` 编译通过
- [ ] `cargo clippy` 无严重警告

## Technical Notes
- 渲染在 `platform/windows/d2d_render.rs`（D2D + DirectWrite）
- 窗口交互在 `platform/windows/wnd_proc.rs`（WM_LBUTTONDOWN 等）
- 标题栏布局在 `platform/windows/grid_window.rs`
- 排序引擎 `box_core/sort_engine.rs` 已实现 8 种维度 × 升降序
- 视图引擎 `box_core/view_engine.rs` 已实现 8 种视图模式
- 分组引擎 `box_core/group_engine.rs` 已实现 8 种分组维度
- 交互状态 `box_core/interaction.rs`
- 桌面图标枚举 `platform/windows/desktop_manager.rs`
- 菜单绘制使用 D2D（与分类框相同的渲染管线）
- 下拉菜单需要处理点击外部关闭（可能需要捕获鼠标或检测点击区域）
