# fix: 分类框重命名输入框 bug 修复

## 目标
修复分类框中图标右键重命名时的两个 UI bug：输入框字体太小、重命名时图标名称文本未隐藏。

## 已知信息
* 重命名使用原生 Windows EDIT 控件（独立线程），实现在 `src/platform/windows/rename_editor.rs`
* EDIT 控件创建后未设置字体（无 WM_SETFONT），导致使用默认极小字体
* 图标名称通过 DirectWrite 在 `d2d_render.rs` 的 `render_icon_grid` 中绘制
* 重命名期间未隐藏正在编辑的图标的名称文本，造成视觉重叠
* `GridWindowData` 中有空的「重命名状态」预留区域

## 临时假设
* 字体大小应与图标标签字体一致（13px at 96 DPI）
* 重命名结束后（确认或取消），需清除重命名状态并刷新渲染

## 需求
1. 重命名输入框使用 Microsoft YaHei UI 字体，大小与图标标签一致（DPI 感知）
2. 重命名输入框显示时，隐藏被重命名图标的名称文本
3. 重命名输入框关闭后，显示最新名称文本（自动更新）

## 验收标准
- [ ] 重命名输入框字体大小合适，与图标标签视觉一致
- [ ] 重命名输入框显示时，对应图标的名称文本不可见
- [ ] 重命名确认/取消后，名称文本正常显示（更新后的名称或原名称）

## 明确排除范围
* 不修改重命名逻辑（文件重命名本身）
* 不修改右键菜单行为
* 不修改图标渲染（仅改文本标签可见性）

## 技术笔记
* `rename_editor.rs` - EDIT 控件创建和消息循环
* `wnd_proc.rs:77-127` - 触发重命名、计算位置
* `d2d_render.rs:633-840` - render_icon_grid 绘制图标标签
* `grid_window.rs:112-196` - GridWindowData 结构定义
