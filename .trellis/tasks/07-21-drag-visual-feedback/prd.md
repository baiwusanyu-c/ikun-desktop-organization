# 拖拽可视化反馈

## 目标
在分类框和覆盖区域内拖拽图标时，增加拖拽过程中的可视化反馈，让用户能够直观感知释放后的操作效果。

## 需求
- **插入指示器**：拖拽 C 到 A 和 B 中间时，未释放时显示垂直分隔线（`A | B`），表示释放后 C 将插入到 A 和 B 之间
- **替换高亮**：拖拽 C 到 A 上时，A 显示与 hover 状态一致的半透明背景色（`【A】 B`），表示释放后 C 将替换 A
- **同框内拖拽**：当前仅实现同框内拖拽的可视化反馈（跨框拖拽暂不涉及）

## 验收标准
- [ ] 拖拽图标经过网格单元格边缘时，显示垂直分隔线指示插入位置
- [ ] 拖拽图标经过网格单元格中心时，该单元格显示半透明背景色（与 hover 一致）
- [ ] 释放鼠标后，可视化反馈消失，执行对应的插入/替换操作
- [ ] 拖拽离开分类框区域时，可视化反馈消失

## 技术笔记
- 在 `GridWindowData` 增加 `drag_over_item: i32`（替换高亮项索引）和 `drag_over_insert_col/row: i32`（插入指示器位置）
- 在 `handle_grid_drag_timer` 中检测光标所在的网格单元格，计算光标在单元格中的相对位置（中心 vs 边缘）
- 在 `d2d_render.rs` 的 `render_icon_grid` 中绘制插入分隔线和替换高亮
- 在 `end_drag` 中清除拖拽覆盖状态
- 分隔线使用 2px 宽的垂直线，颜色与 hover 背景一致
- 替换高亮复用现有 `hover_brush`
