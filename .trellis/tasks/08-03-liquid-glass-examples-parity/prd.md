# 分类框液态玻璃效果对齐 liquid-glass-rs 示例

## 目标

Windows 平台分类框只对背景应用与 `D:\github-project\liquid-glass-rs\examples\frosted_liquid` 一致的液态玻璃渲染；文字、图标和交互层保持原样。控制面板使用示例中的配置项，改动实时反馈并持久化；关闭时回退到 930a6184 之前的半透明背景。

## 已知信息

- liquid-glass-rs 示例的核心参数为位移强度、模糊程度、饱和度、色差偏移、弹性、圆角半径、明亮区域处理和折射贴图模式。
- 示例使用 Desktop Duplication 捕获桌面、D3D11 shader 采样与模糊/折射合成，并对圆角区域生成 alpha。
- 当前项目已有 Windows `liquid_glass` 渲染模块、分类框 D2D 绘制入口和配置字段，但设置面板仍包含重复/过时参数，且需要校准示例 shader 与生命周期。
- 当前工作树存在其他未提交改动，均视为用户已有变更，不在本任务中回滚。
