# 图标右键菜单：剪切、重命名、删除功能

## 目标
为覆盖区域和分类框中的图标实现剪切、重命名、删除的右键菜单功能，确保操作后文件状态持久化。

## 需求
1. **剪切**: 右键菜单点击剪切后，在其他位置粘贴时，覆盖区域或分类框中对应图标应被移除
2. **删除**: 右键菜单点击删除后，图标从覆盖区域或分类框中移除，且文件被永久删除（程序退出后文件也不存在）
3. **重命名**: 右键菜单点击重命名后，显示内联编辑框（类似原生桌面 F2 重命名），确认后文件被实际重命名（程序退出后文件名也是新的）

## 验收标准
- [ ] 覆盖区域图标右键菜单包含剪切、重命名、删除
- [ ] 分类框图标右键菜单包含剪切、重命名、删除
- [ ] 删除操作永久删除文件（包括 vault 副本）
- [ ] 重命名操作实际重命名磁盘文件（包括 vault 副本）
- [ ] 重命名交互与原生桌面一致（内联编辑框，选中文件名不含扩展名）
- [ ] 剪切操作将文件放入剪贴板（移动语义），粘贴后原图标从框中移除
- [ ] 所有操作后 UI 即时刷新
