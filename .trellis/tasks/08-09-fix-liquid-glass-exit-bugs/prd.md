# 修复液态玻璃效果与程序退出还原 Bug

## 目标
修复控制面板中液态玻璃效果的 UI 问题以及程序退出时图标未还原到桌面的逻辑 bug。

## 需求
- Bug 1：slider 组件和默认值显示位置不一致（可能是小数精度问题）
- Bug 2：液态玻璃效果中设置折射贴图换货亮区减弱折射后，控制面板窗口底部有异常空白区域
- Bug 3：程序退出后，分类框收纳的图标没有复原到桌面（需对比 37b6507b 无 Tauri 版本的退出逻辑）

## 验收标准
- [x] slider 默认值与实际位置一致
- [x] 液态玻璃折射贴图/亮区减弱折射设置后，控制面板窗口底部无异常空白
- [x] 程序退出后，分类框中收纳的图标正确还原到桌面原始位置
- [x] 自检是否还有其他类似问题

## 技术笔记
- 涉及前端 Svelte slider 组件、液态玻璃渲染、Rust 退出清理逻辑
- 需要对比 commit 37b6507b（Tauri 集成前）的退出逻辑
