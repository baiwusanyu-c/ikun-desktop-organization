# 分类框实时液态玻璃与高斯模糊

## 目标

在 Windows 分类框中实现实时液态玻璃背景。分类框移动或缩放时按新的屏幕位置持续采样桌面，使用可分离高斯模糊柔化颜色，并叠加轻量折射、边缘高光与阴影，同时保留现有图标、文字和交互行为。

## 需求

- 使用 D3D11 与 DXGI Desktop Duplication 捕获分类框所在显示器。
- 同一显示器上的多个分类框共享一份桌面捕获资源，不为每个框重复创建 duplication。
- 使用水平、垂直两遍高斯模糊，避免单次大范围二维采样。
- 分类框移动、缩放和桌面内容变化时持续更新玻璃背景。
- 玻璃背景先绘制，现有图标、文字、hover、选中和拖拽反馈后绘制。
- 捕获、Shader、设备或显示模式异常时回退到现有半透明圆角背景。
- 避免分类框自身进入桌面捕获造成递归反馈。

## 验收标准

- [ ] 红黄蓝绿四分区桌面上，四个分类框移动到不同分区时分别显示对应区域颜色。
- [ ] 分类框跨分区移动时颜色连续变化，并在边界处呈现高斯柔和混合。
- [ ] 四个分类框不会分别创建同一显示器的 Desktop Duplication。
- [ ] 图标、标签、菜单、拖拽、缩放和 DPI 行为保持可用。
- [ ] 捕获不可用时分类框仍能以原半透明背景显示。
- [ ] `cargo fmt -- --check`、`cargo check`、`cargo test` 和 `cargo clippy` 通过。

## 技术笔记

- 新增 Windows 平台液态玻璃渲染模块，使用线程本地共享捕获管理器，匹配现有窗口同线程消息模型。
- GPU 管线：桌面纹理裁剪采样 -> 水平高斯模糊 -> 垂直高斯模糊与液态玻璃合成 -> staging texture 回读 -> D2D 背景位图。
- 初版保留 `UpdateLayeredWindow` 和现有 D2D 图标渲染，后续可迁移 DirectComposition 消除 GPU 回读。
- 目标刷新率 30 FPS；只在液态玻璃启用且窗口可见时运行。
