# 分类框UI交互优化

## Goal
优化分类框内快捷方式图标的视觉交互体验，修复文字间距 bug，增强可读性和交互反馈。

## Requirements

### R1: 修复单行文本选中时间距缩小
- **问题**: 图标名称只有一行时，选中后图标与文字之间间距缩小，文字发生位移
- **约束**: 不能影响"省略号显示时，选中显示完整文本"功能
- **期望**: 无论单行还是多行文本，选中前后图标与文字间距保持一致

### R2: 增亮图标名称文本颜色
- **问题**: 名称文本在分类框背景下偏暗，难以看清
- **期望**: 文本颜色更亮，在分类框背景下清晰可读

### R3: 添加 hover 背景效果
- **现状**: 选中时整个快捷方式图标有深色背景效果
- **期望**: 鼠标 hover 时也有背景色效果，但比选中色浅，以区分 hover 和选中状态
- **优先级**: 选中 > hover > 默认（无背景）

### R4: 添加 hover tooltip
- **期望**: 鼠标 hover 到快捷方式图标上时，显示类似 HTML title 属性的 tooltip
- **内容**: 展示完整的快捷方式图标名称文本
- **触发**: 仅在分类框处于选中状态时，hover 快捷方式图标显示 tooltip

## Acceptance Criteria
- [ ] 单行文本选中前后无文字位移
- [ ] 省略号+选中完整文本功能正常
- [ ] 文本颜色明显增亮，在分类框背景下清晰可读
- [ ] hover 时显示浅色背景，选中时显示深色背景，两者可区分
- [ ] hover 时 tooltip 显示完整名称
- [ ] 所有修改通过 `cargo fmt` 和 `cargo clippy`

## Technical Notes
- 主要修改文件: `src/ui/icon_widget.rs`（图标组件）和可能的 `src/ui/box_widget.rs`
- 涉及 egui 的 `Response`、`hovered()`、`on_hover_text()` 等 API
- 需要注意选中状态和 hover 状态的组合逻辑
