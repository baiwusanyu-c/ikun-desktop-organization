我想实现一个应用程序，根据我的需求拆分任务，优先支持 windows 平台
* 本应用程序基于 rust 编写
* 本应用程序支持 windows10 和 windows11，如果可以，我期望能够支持 macos
* 应用程序能够开机自启
* 应用程序能够对桌面的快捷图标进行分类，可以根据快捷图标程序的功能进行一键智能分类
* 分类的图标会被一个方框所包裹，类似手机系统的左面的文件夹，不同的图标构成的方框为一个类似‘文件夹’概念的分类集合，我们称之为分类框，整个桌面支持由若干个图标构成的多个分类框。
* 分类框支持用户拖拽改变尺寸
* 分类框支持圆角风格设置
* 分类框支持背景色设置（颜色、透明的、毛玻璃、macos 液态玻璃等效果）
* 分类框支持命名
* 分类框内的快捷图标按照 grid 布局进行排列
* 分类框可以支持包括其快捷图标在内的整体在桌面进行任意拖拽摆放，用户可以将其放到桌面任何位置
* 分类框支持锁定，锁定后持包括其快捷图标在内的整体用户不能拖拽改变位置
* 所有分类框会自动记忆桌面布局，下次开机时，分类框依旧在对应的位置
